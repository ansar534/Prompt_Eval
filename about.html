About Prompt Eval

Prompt Eval is a lightweight Python project designed to evaluate the performance of different Large Language Models using a curated set of prompt files. It reads prompts, sends them to selected providers such as Gemini and Groq, and saves the generated outputs as PDF documents for review and comparison.

What this project does

The repo organizes prompts into numbered folders such as Q1, Q2, and Q3, loads each prompt text, invokes an AI model, and captures the result in an output folder. This makes it easy to compare model behavior across the same set of questions.

How it works

  • Reads prompt files from the project prompt directories.
  • Loads model configuration from YAML files under the config folder.
  • Runs the prompt through Gemini or Groq clients.
  • Converts the generated responses into PDF files for saving and review.

Core technologies

  • Python 3
  • LangChain
  • Google Generative AI
  • Groq API
  • ReportLab for PDF generation
  • YAML for configuration

Quick start

Install dependencies:

pip install -r requirements.txt

Set your environment keys, then run:

python src/main.py

The project writes generated outputs to folders such as:

output/gemini/ and output/groq/
