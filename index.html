Prompt Eval

A lightweight AI prompt-evaluation project for comparing model responses across providers. It reads prompt files, runs them through Gemini and Groq, and exports the outputs as PDF documents for review and comparison.

About the project Read the README

What it does

Prompt Eval helps researchers, developers, and teams compare how different LLMs answer the same set of questions.

How it works

  • Loads prompt files from question folders
  • Uses YAML config for model settings
  • Runs prompts through Gemini and Groq
  • Exports results as PDFs for comparison

Tech stack

  • Python
  • LangChain
  • Gemini API
  • Groq API
  • ReportLab
Built for AI model comparison and prompt evaluation.
